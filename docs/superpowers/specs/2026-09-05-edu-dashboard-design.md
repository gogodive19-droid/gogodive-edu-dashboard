# 고고다이브 강습 현황 대시보드 — 설계 문서

작성일: 2026-09-05 · 상태: 사용자 승인

## 목적

예약 시스템에서 내려받은 "통계분석_그룹수업" 엑셀(2024-01 ~ 2026-08, 파일 3개)을
강사별 · 수업종류별 · 강습장별로 월 단위 분석해 운영진이 한눈에 보는 대시보드.
매월 말 같은 양식의 엑셀 3개(해당 월만)를 받아 재발행한다.

## 발행

- 단일 `index.html` 을 StatiCrypt(AES) 로 암호화 → 공개 저장소 `gogodive19-droid/gogodive-edu-dashboard` → GitHub Pages
- URL: https://gogodive19-droid.github.io/gogodive-edu-dashboard/
- 비밀번호는 저장소·파일에 남기지 않는다. 노션 허브 페이지에만 링크와 함께 적는다.
- 노션 허브: https://app.notion.com/p/3d239eba97ed800381eaff13cbf68037

## 데이터 규칙 (사용자와 확정)

| 항목 | 결정 |
|---|---|
| 0명 수업 | 횟수·인원구간표에서 제외, "개설 후 0명 N회" 참고 숫자로만 표시 |
| 인원 | `출석` 컬럼 |
| 중복 (같은 수업일시+강사+수업명) | 출석이 가장 적은 1건만 남김 |
| 프리다이빙 이론 [LIVE] | 완전 제외 |
| 파일 3개 | 구분 없이 합침 |
| 월별 업데이트 | 해당 월 파일 3개 추가. 중복 규칙이 겹침을 흡수 |
| 수업종류 단위 | 대분류 13개 기본, 토글로 세부 전환 |
| 딥풀 코칭반 | 딥풀 상품 파일(두 번째 엑셀)의 "(강습장 약칭) 코칭반" 표기(용인 딥스·시흥 파라·가평 K26)는 별도 대분류 "딥풀 코칭반". 초급 상품 표기 "(코칭반) 강습장"은 딥풀 강습장이어도 일반 코칭반 (2026-09-05 추가 확정) |
| 인원 구간 | 1~10명 각각 + 11명 이상 |
| 기간 | 월 선택(기본 최신 월) + 기간 선택, 월별 추세 차트 |

수업명 정규화 규칙의 단일 소스는 `build/mapping.py`. 규칙에 없는 수업명이 나오면 빌드가 실패한다.

## 화면

공통 상단: 기간 선택 · 수업종류 단위 토글(대분류/세부). URL 해시로 상태 공유.

1. **전체 현황** — KPI(수업 횟수, 총 인원, 평균 인원, 활동 강사, 0명 수업; 전월 대비) · 월별 추세 · 대분류별 · 강습장별
2. **강사별** — 강사 선택 → 수업종류별 표 / 수업종류×인원구간 매트릭스 / 강습장별 표 / 강습장×인원구간 매트릭스 / 월별 추세
3. **수업종류별** — 수업종류 선택 → 강사별 / 강습장별 (표+매트릭스) / 월별 추세
4. **강습장별** — 강습장 선택 → 강사별 / 수업종류별 (표+매트릭스) / 월별 추세

매트릭스 셀 = 횟수, 토글로 행 대비 %. 우측 합계 열에 횟수와 전체 대비 %.

## 파이프라인

`data/raw/*.xlsx` → `build/build.py` (정규화 · 중복 · 집계) → `dist/data.json`, `dist/index.html`
→ `npx staticrypt` → `index.html` (암호화) → git push → GitHub Pages.

집계 단위는 `(월, 강사, 세부수업, 강습장, 출석인원) → 횟수` 셀. 모든 화면은 이 셀을 합산해 만든다.
